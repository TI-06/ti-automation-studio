# Excel差分比較・変更箇所チェッカー 設計

## 1. 目的

2つのExcelファイルをブラウザ内で比較し、値・行・列・シート・数式の変更を非エンジニアでも理解できる形で表示し、結果を保存できる無料ツールを提供する。

URL: `/tools/excel-diff`

主な検索意図:

- Excel 差分 比較
- Excel 比較 ツール
- Excel 変更箇所
- Excel ファイル 比較

## 2. 対応形式

- `.xlsx`
- `.xls`

CSV同士の比較は初期スコープ外。CSVはデータ整理ツールへ誘導する。

ファイルは外部サーバーへ送信せず、ブラウザ内で解析する。

## 3. 基本フロー

1. 変更前ファイルを選択
2. 変更後ファイルを選択
3. ファイル構成を解析
4. 比較対象シートを選択
5. 行の照合方法を選択
6. 比較実行
7. 差分を確認・絞り込み
8. Excel / CSV / 印刷向け結果を保存

## 4. 初期画面

見出し:

**2つのExcelファイルを比較します**

左右に以下を配置する。

- 変更前のファイル
- 変更後のファイル

各領域でファイル選択とドラッグ&ドロップに対応する。

補助導線:

- サンプルデータで試す
- 対応形式を見る

ファイル選択付近に以下を明記する。

> ファイルは外部サーバーへ送信されません。このブラウザ内で比較します。

## 5. ファイル解析結果

比較前に両ファイルの概要を表示する。

例:

- ファイル名
- ファイルサイズ
- シート数
- 選択シートの行数 / 列数

両ファイルに同名シートがあれば候補を自動選択する。

片方にしか存在しないシートは「追加されたシート」「削除されたシート」として構造差分候補にする。

## 6. 行の照合方法

### 6.1 行番号で比較

同じ行番号同士を比較する。

向いているケース:

- 並び順が変わらない
- 行追加・削除が少ない

### 6.2 行を特定する列で比較

ユーザーが1列以上を選ぶ。

例:

- 商品コード
- 社員番号
- 伝票番号
- 店舗コード + 商品コード

画面文言では「主キー」「複合キー」を使わず、**行を特定する列**と表現する。

複数列を組み合わせられる。

UI例:

`店舗コード ×`  `商品コード ×`  `＋ 列を追加`

## 7. キー値の検証

比較実行前に以下を確認する。

- 空欄キー
- 重複キー
- 変更前/変更後で選択列が存在するか

重複があれば比較を開始せず、日本語で修正方法を案内する。

例:

**「商品コード」に重複があります**

同じ商品コード「A001」が3行見つかりました。別の列を追加して行を特定するか、重複データを確認してください。

## 8. 差分種別

初期版で検出する。

- セル値変更
- 行追加
- 行削除
- 列追加
- 列削除
- シート追加
- シート削除
- 数式変更

値と数式は別カテゴリとして扱う。

数式セルでは、計算結果が同じでも数式自体が変わっていれば「数式変更」にする。

## 9. 書式差分

初期版では、セル色・罫線・フォント等の全面的な書式比較は標準機能に含めない。

理由:

- Excel内部書式は複雑で誤検知が多くなりやすい
- 実務上、値差分が埋もれる可能性がある
- ブラウザ負荷が増える

将来、基本書式比較を追加する場合も標準OFFとする。

数値表示形式等が比較精度に影響する場合は、内部値を基準に比較する。

## 10. 比較進捗

処理段階を表示する。

1. ファイルを読み込んでいます
2. シート構成を確認しています
3. 行を照合しています
4. 変更箇所をまとめています

大量行では進捗件数を出す。

例:

`8,420 / 22,500行を照合中`

重い処理はWeb Workerで実行する。

## 11. 結果サマリー

上部にクリック可能な集計を表示する。

- 変更
- 追加
- 削除
- 数式変更
- 構造変更

各数値を押すと一覧をその種別へ絞り込む。

## 12. 比較グリッド

PCではExcelに近い高密度グリッドを表示する。

最低表示項目:

- 状態
- 行を特定する列
- 変更された列
- 変更前
- 変更後

表示モードを2つ持たせる。

### 差分一覧

変更箇所だけを一覧表示する。

### シート比較

元シートの表形式に近い形で変更箇所をマーキングする。

初期表示は差分一覧とし、大規模ファイルでも結果を理解しやすくする。

## 13. 色と状態表現

色だけに依存しない。

- 変更: ゴールド系 + 「変更」ラベル
- 追加: 青緑系 + 「追加」ラベル
- 削除: 赤系 + 「削除」ラベル
- 数式変更: 紫寄りの補助色 + 「数式」ラベル

サイト全体の黒・濃紺・アイボリー・シャンパンゴールドを崩さない。

## 14. 差分詳細パネル

選択した差分について表示する。

- シート
- セルまたは行
- 項目名
- 変更前
- 変更後
- 数値の場合は増減量
- 数式の場合は変更前数式 / 変更後数式

値が長い場合は省略せず展開可能にする。

## 15. 絞り込み

最低限以下を提供する。

- 差分種別
- シート
- 変更された列
- 文字列検索

「変更なし」を大量表示しない。

## 16. 結果保存

### Excel

主な保存形式。

出力ブックのシート例:

- 比較概要
- 変更一覧
- 追加一覧
- 削除一覧
- 数式変更一覧
- 構造変更一覧

比較概要には以下を入れる。

- 変更前ファイル名
- 変更後ファイル名
- 比較日時
- 比較方法
- 行を特定する列
- 各差分件数

### CSV

現在表示している差分一覧をCSVで保存できる。

### 印刷 / PDF

ブラウザ印刷で比較概要と差分一覧を保存しやすい印刷CSSを用意する。

## 17. サンプルデータ

ログイン不要で「サンプルデータで試す」を提供する。

サンプルには以下を含める。

- 値変更
- 行追加
- 行削除
- 数式変更

初回利用者がファイルを用意しなくても機能を確認できること。

## 18. 制限

初期目安:

- 各ファイル20MBまで
- 対象シート100,000行まで
- 50,000行超では処理時間注意を表示

パスワード保護されたExcelは対象外とし、分かりやすいメッセージを出す。

マクロ自体の比較・VBAコード比較は対象外。

## 19. SEO説明コンテンツ

ツール本体の下に以下を配置する。

- このツールでできること
- Excel差分比較が必要になる例
- 行番号比較と行を特定する列の違い
- 数式変更について
- ファイルの安全性
- よくある質問
- 関連サービス / 開発実績

## 20. 成功条件

- 初見ユーザーが迷わず2ファイルを投入できる
- 途中行追加があってもキー列比較で誤差分を抑えられる
- 差分種別と変更前後が即座に分かる
- 大規模比較でも画面が固まったように見えない
- 結果をExcelで持ち帰れる
- ファイルが外部へ送信されないことが明確
