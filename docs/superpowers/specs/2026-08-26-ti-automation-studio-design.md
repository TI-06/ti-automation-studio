# TI AUTOMATION STUDIO サイト設計書

作成日: 2026-08-26

## 1. 目的

今後の受注獲得につなげるため、GitHubとCloudflareを基盤に、実績・対応領域・公開ツール・問い合わせ導線をまとめた営業用Webサイトを構築する。

転職向けの一般的なエンジニアポートフォリオではなく、「業務改善・自動化・小規模システム開発を依頼できる開発スタジオ」として見せる。

主要KPIは以下とする。

- 問い合わせ数
- 実績詳細ページへの遷移率
- 公開ツールの閲覧・利用数
- 営業メール等からのサイト到達後の問い合わせ率

## 4. ターゲット

主対象は中小企業・個人事業主・小規模チームの担当者。

- Excel作業を減らしたい
- Googleスプレッドシートを業務システム化したい
- PDF・帳票を自動生成したい
- EC・外部サービスをAPI連携したい
- 手作業のデータ処理を自動化したい
- 既存のExcel/VBA/GASを改修したい
- 小規模なWeb管理システムを作りたい
- AIを業務に組み込みたい

技術に詳しくない依頼者にも理解できる表現を優先する。

## 5. デザイン方針

### コンセプト

「個人開発者のポートフォリオ」ではなく「少人数の高品質な開発スタジオ」に見えること。

### トーン

- 高級感
- 静か
- 信頼感
- 技術的
- 過度にAIっぽくしない
- 派手なグラデーションや光彩を多用しない

### カラー

- 背景: Warm Black `#0B0C0E`
- Surface: `#111317`
- Main Text: Ivory White `#F2F0EA`
- Sub Text: Gray `#A8A8A2`
- Accent: Champagne Gold `#C8A96B`
- Border: 低コントラストの半透明線

### UI

- 大きな余白
- 太すぎない大見出し
- グリッドベース
- 角丸は小さめ
- 強い影は使用しない
- 1px境界線中心
- 数字・成果を大きく表示
- カードは均一に並べすぎず編集的なレイアウトにする
- PC/スマホともに読みやすいレスポンシブ設計

### Motion

- 初回表示の短いFade / Translate
- セクション出現時の軽いReveal
- ボタン・カードの控えめなHover
- 常時動く大きな背景アニメーションは使用しない
- `prefers-reduced-motion` を尊重する

## 10. 公開ツール方針

既存GitHubリポジトリを無条件でサイトに掲載しない。

公開前チェック:

- 秘密情報がコミット履歴に存在しない
- 顧客情報が存在しない
- 個人情報が存在しない
- READMEが整備されている
- 動作確認済み
- UI品質が営業サイトの水準を下げない
- ライセンス・利用規約に問題がない

営業上の訴求力が高いものを3〜6個に限定する。

必要に応じてポートフォリオ専用の小型デモを新規作成する。

## 12. 問い合わせ構成

### 入力項目

- 名前または会社名（任意）
- メールアドレス（必須）
- 相談カテゴリ
- 現在困っていること（必須）
- 希望内容
- 予算感（任意）
- 希望時期（任意）
- 個人情報取扱いへの同意

### Bot対策

Cloudflare Turnstileを使用し、サーバー側で検証する。

### 通知

初期版は無料運用を優先する。

1. ブラウザ → `/api/contact`
2. Cloudflare側でTurnstile検証
3. 入力値を検証
4. 非公開のGoogle Apps Script Web Appへ送信
5. GAS側でスプレッドシート保存
6. GASから管理者メールへ通知

Worker → GAS間には共有シークレットを設定し、メールアドレスやGAS URLをフロントエンドに埋め込まない。
