# CSV・Excel データ整理・クレンジングツール 設計

## 1. 目的

CSVまたはExcelをブラウザ内で解析し、重複・余分な空白・空欄・全角半角・日付形式・数値形式・不要改行・表記ゆれ等を「見つける → 内容を確認する → 選んで直す → 保存する」無料ツールを提供する。

URL: `/tools/data-cleaner`

主な検索意図:

- CSV 重複 削除
- CSV データ 整形
- Excel データ クレンジング
- Excel 重複 チェック
- Excel 空白 削除

## 2. 対応形式

- `.csv`
- `.xlsx`
- `.xls`

ファイルは外部サーバーへ送信しない。

CSVではUTF-8とShift_JISを主要対象とし、文字コードを自動判定する。判定に確信がない場合はユーザーへ選択を求める。

## 3. 基本フロー

1. ファイルを選択
2. ファイル形式・文字コードを確認
3. データを解析
4. 「データ健康診断」を表示
5. 修正候補をカテゴリ別に確認
6. 適用する修正だけ選択
7. 変更内容をプレビュー
8. 修正実行
9. 必要なら元に戻す
10. CSV / Excelとして保存

## 4. 初期画面

見出し:

**CSV・Excelのデータを整理します**

補足:

**重複、余分な空白、表記の違いなどを見つけて、必要な修正だけまとめて適用できます。**

ファイル選択付近に以下を明記する。

> ファイルは外部サーバーへ送信されません。このブラウザ内で処理します。

「サンプルデータで試す」も提供する。

## 5. データ健康診断

読込後、まず修正せず問題候補だけを解析する。

サマリー例:

**8種類の整理候補が見つかりました**

カテゴリ:

- 重複している行
- 前後の余分な空白
- 空欄
- 全角・半角の混在
- 日付形式の混在
- 数値形式の混在
- セル内の不要な改行
- 似た表記の値

各カテゴリは件数と代表例を表示する。

## 6. 自動修正の原則

解析しただけではデータを書き換えない。

各候補に対して、ユーザーが明示的に「この修正を適用する」を選択した場合のみ変更する。

変更前には必ずプレビューを表示する。

## 7. 空白・不要文字

対象:

- 文字列先頭の空白
- 文字列末尾の空白
- 連続スペース
- セル内の不要な改行
- 制御文字の一部

例:

`"株式会社ABC " → "株式会社ABC"`

全角スペースを通常スペースへ変換する機能は、ユーザーが選択した場合のみ実施する。

## 8. 全角・半角

列単位で修正可能にする。

対象候補:

- 全角数字 → 半角数字
- 全角英字 → 半角英字
- 半角カナ / 全角カナは、意図しない表記変更を避けるため初期版では別の確認項目にする

ユーザーが対象列を確認してから適用する。

## 9. 日付形式

同一列で複数の日付表記が混在している場合に候補を表示する。

例:

- `2026/08/27`
- `2026-08-27`
- `2026年8月27日`

ユーザーは統一形式を選択する。

候補:

- `YYYY/MM/DD`
- `YYYY-MM-DD`
- `YYYY年M月D日`

日付として確実に解釈できない値は自動変換せず「確認が必要」に残す。

## 10. 数値形式

同一列に数値・文字列数値・桁区切り等が混在する場合に候補を出す。

例:

- `1200`
- `1,200`
- `１２００`

変換後に意味が変わる可能性がある郵便番号・商品コード・社員番号などは、列型の推測だけで強制的に数値化しない。

## 11. 重複チェック

ユーザーが「重複判定に使う列」を1つ以上指定する。

例:

- メールアドレス
- 商品コード
- 会社名 + 電話番号

画面文言では「複合キー」を使わない。

重複結果はグループ化して表示する。

各グループで以下を選べる。

- 先頭の行を残す
- 最後の行を残す
- 手動で残す行を選ぶ
- 今回は削除しない

一括処理を行う場合でも削除件数を事前表示する。

## 12. 空欄チェック

列ごとに空欄件数を表示する。

空欄の自動補完は初期版では限定する。

可能な操作:

- 空欄行だけ表示
- 空欄を指定文字で埋める
- 対象行を削除候補にする

平均値・推測値などを自動挿入する処理は行わない。

## 13. 表記ゆれ候補

文字列の正規化後に近い値を候補として表示する。

例:

- `株式会社ABC`
- `株式会社ＡＢＣ`
- `株式会社ABC `

電話番号:

- `090-1234-5678`
- `09012345678`

初期版では「候補提示」までを基本とし、ユーザーが統一先を選ぶ。

類似度が低い値を勝手に同一扱いしない。

## 14. 列詳細パネル

列名を選択すると右側に以下を表示する。

- 列名
- データ件数
- 空欄
- 重複
- 修正候補数
- 推定されるデータ種類

その下に「この列でできること」を日本語で表示する。

例:

- 前後の空白を削除
- 全角数字を半角へ
- 日付形式を統一
- 重複を確認
- 空欄を確認

## 15. 変更プレビュー

修正適用前に、変更予定を一覧表示する。

表示項目:

- 行番号
- 列名
- 変更前
- 変更後
- 修正理由

例:

`18 / 会社名 / "ABC株式会社 " / "ABC株式会社" / 末尾の空白`

個別に「この変更を除外」が可能。

## 16. 変更履歴と元に戻す

ユーザーが実行した処理を履歴として保持する。

例:

1. 前後の空白を削除 317件
2. 全角数字を半角へ 51件
3. 重複を削除 18行

各操作単位で「元に戻す」を提供する。

ページを閉じた後まで履歴をクラウド保存しない。

## 17. 処理進捗

例:

1. ファイルを読み込んでいます
2. 列の内容を確認しています
3. 重複や表記の違いを探しています
4. 診断結果をまとめています

重い診断処理はWeb Workerで行う。

## 18. 保存

### CSV

現在の整理済みデータをCSVとして保存する。

文字コード選択:

- UTF-8
- Shift_JIS

### Excel

整理済みデータをExcelとして保存する。

オプション:

**変更内容一覧も一緒に保存**

有効時は「変更履歴」シートを追加する。

保存前に最終件数を表示する。

例:

- 元データ 8,421行
- 整理後 8,403行
- 修正セル 368件
- 削除行 18件

## 19. サンプルデータ

以下を含むサンプルを用意する。

- 前後空白
- 全角数字
- 重複
- 空欄
- 日付形式混在
- 電話番号表記違い

サンプルを読み込むと診断→修正→保存まで体験できる。

## 20. 制限

初期目安:

- 1ファイル20MBまで
- 100,000行まで
- 50,000行超で注意表示

複数シートExcelでは、初期版は一度に1シートを編集対象とする。別シートへ切り替える際、未保存変更があれば確認する。

## 22. 成功条件

- 読み込むだけで「どこを整理すべきか」が分かる
- ユーザー承認なしにデータを書き換えない
- 修正前後を確認できる
- 誤修正を個別除外・元に戻せる
- CSV / Excelとして持ち帰れる
- 業務データを外部サーバーへ送信しない
