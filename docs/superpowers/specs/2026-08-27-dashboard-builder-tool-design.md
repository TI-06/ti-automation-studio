# Excel・CSV ダッシュボード自動作成ツール 設計

## 1. 目的

ExcelまたはCSVをブラウザ内で読み込み、列の種類を判定し、業務ユーザーでも少ない設定でKPI・グラフ・ランキング・集計表を作成できる無料ツールを提供する。

URL: `/tools/dashboard-builder`

このツールは検索流入だけでなく、TI AUTOMATION STUDIOのデータ処理・UI・業務設計力を示す代表的な公開ツールとする。

## 2. 対応形式

- `.csv`
- `.xlsx`
- `.xls`

ファイルは外部サーバーへ送信せず、ブラウザ内で処理する。

複数シートExcelでは、最初に分析対象シートを1つ選択する。

## 3. 基本フロー

1. ファイルを選択
2. データを解析
3. 列の種類を確認
4. ダッシュボード候補を自動生成
5. KPI・グラフ・表を確認
6. 必要に応じて編集
7. 絞り込み条件を利用
8. 画像 / PDF / Excelで保存
9. 必要ならダッシュボード設定を保存

## 4. 初期画面

見出し:

**Excel・CSVからダッシュボードを作成します**

補足:

**データを読み込み、集計・推移・ランキングを自動で見える化します。**

ファイル選択付近に以下を表示する。

> ファイルは外部サーバーへ送信されません。このブラウザ内で集計します。

「サンプルデータで試す」を提供する。

## 5. 列の種類判定

ファイル読込後、各列を以下の種類へ推定する。

- 日付
- 数値
- 分類
- 文字列
- ID / コード候補

推定結果は確定ではなく、ユーザーが変更可能。

確認画面例:

- 売上日 → 日付
- 店舗 → 分類
- 担当者 → 分類
- 売上額 → 数値
- 商品コード → ID / コード

列名だけでなく、実際の値も使って判定する。

郵便番号・商品コードなど、数字だけでも集計値にすべきでない列を数値KPIとして自動採用しない。

## 6. 自動生成ルール

AIは使用しない。

列の種類と件数からルールベースで候補を生成する。

### KPI候補

数値列から:

- 合計
- 件数
- 平均
- 最大
- 最小

すべてを自動表示せず、代表的な数値列を優先する。

### 時系列候補

日付列 + 数値列がある場合:

- 日別
- 月別
- 年月別

データ期間に応じて初期粒度を選ぶ。

### 分類別集計

分類列 + 数値列がある場合:

- 棒グラフ
- 横棒グラフ
- ランキング

### 構成比

分類種類が少ない場合のみ円 / ドーナツ系の候補を許可する。

カテゴリ数が多い場合は円グラフを自動生成しない。

## 7. 初期ダッシュボード

例: 売上データ

上部:

- 売上合計
- 取引件数
- 平均売上
- 最大売上

中段:

- 月別売上推移
- 店舗別売上

下段:

- 担当者別ランキング
- 商品カテゴリ別集計
- 上位10件

必ず「なぜこのグラフが出たか」がユーザーに理解できる列名を表示する。

## 8. グラフ追加

**＋ グラフを追加**から設定する。

設定項目は日本語で表示。

- 表示形式
- 集計する値
- 分類する項目
- 集計方法
- 表示件数

表示形式:

- 棒グラフ
- 横棒グラフ
- 折れ線グラフ
- 円 / ドーナツグラフ
- 集計表
- ランキング
- KPI数値

専門的なBI用語を前面に出さない。

## 9. 集計方法

初期対応:

- 合計
- 件数
- 平均
- 最大
- 最小

日付の場合は日 / 月 / 年月単位でまとめられる。

## 10. レイアウト編集

各ウィジェットはドラッグで並び替え可能にする。

サイズは自由リサイズではなく、壊れにくいプリセット制にする。

- 小
- 中
- 大

モバイルではドラッグ編集より、上下移動ボタンを優先してもよい。

## 11. 絞り込み

データ内容からフィルター候補を生成する。

例:

- 期間
- 店舗
- 担当者
- 商品カテゴリ

フィルター変更時は関連するKPI・グラフ・表を連動更新する。

現在の絞り込み条件を画面上部で確認できること。

**すべて解除**を用意する。

## 12. データ表

ダッシュボードだけではなく、元データの確認タブを持つ。

機能:

- 列並べ替え
- 簡易検索
- 現在の絞り込み結果表示

初期版では元データの編集は行わない。編集用途はデータ整理ツールへ誘導する。

## 13. 色とグラフデザイン

TI AUTOMATION STUDIOのブランドを維持する。

基本:

- 暗い背景
- アイボリー文字
- シャンパンゴールドを主要系列
- ブルーグレー等を補助系列

複数系列では識別可能な色を追加するが、派手なBIダッシュボードにしない。

色だけで系列を判定させず、凡例・ラベル・ツールチップも使う。

## 14. 数値表示

大きなKPIでは、日本語ユーザーが読みやすい桁区切りを使う。

例:

`12,450,000`

金額記号は元データだけでは断定しない。列名・表示形式から明確な場合だけ候補を出し、ユーザーが変更可能にする。

## 15. 処理進捗

例:

1. ファイルを読み込んでいます
2. 列の種類を確認しています
3. 集計候補を作っています
4. ダッシュボードを作成しています

大規模データ集計はWeb Workerへ分離する。

グラフ再集計中も、小さな状態表示を出し、操作不能なのか処理中なのか分かるようにする。

## 16. 保存

### 画像

ダッシュボード全体を画像として保存できる。

### PDF

印刷・共有向けにA4横を基本としたPDF保存レイアウトを用意する。

長いダッシュボードは複数ページになることを許容する。

### Excel

現在の集計結果をExcelとして保存する。

例シート:

- 集計概要
- グラフ元データ
- 絞り込み済みデータ

### 設定ファイル

ダッシュボード構成をJSON設定ファイルとして保存できる。

保存対象:

- 使用列
- KPI設定
- グラフ種類
- 集計方法
- 並び順
- サイズ
- フィルター構成

ユーザーデータ本体は設定ファイルに含めない。

次回、同じ列構成の新しいファイルと設定ファイルを読み込むことで、同じダッシュボード構成を再現できる。

## 17. 設定ファイル再読込

列が不足している場合は処理を中止せず、該当ウィジェットだけ「列が見つかりません」と表示し、再設定できるようにする。

列名一致を基本とし、曖昧な自動置換はしない。

## 18. サンプルデータ

売上データを模した匿名サンプルを用意する。

含める列例:

- 日付
- 店舗
- 担当者
- カテゴリ
- 数量
- 売上額

読み込むだけで、KPI・時系列・店舗別・ランキングが見える構成にする。

## 19. 制限

初期目安:

- 1ファイル20MBまで
- 100,000行まで
- 50,000行超で注意表示

1画面に生成するウィジェット数には上限を設ける。初期上限は12個程度を想定し、性能試験で確定する。

初期版では以下を対象外とする。

- 複数ファイル結合
- データベース接続
- API接続
- クラウド保存
- 共同編集
- 自動更新

## 20. SEO説明コンテンツ

ツール下部に以下を配置する。

- どんなExcel・CSVに向いているか
- 自動生成されるグラフの考え方
- 列の種類判定について
- ダッシュボード設定の保存方法
- ファイルの安全性
- よくある質問
- 関連サービス / 開発実績

## 21. 成功条件

- 非エンジニアがファイル投入からダッシュボード生成まで進める
- 自動生成結果が過剰でなく、実務で読める
- 必要なグラフを日本語UIだけで追加できる
- フィルターで全体が連動する
- 画像 / PDF / Excel / 設定として持ち帰れる
- 画面自体がTI AUTOMATION STUDIOの技術力を示す品質になる
